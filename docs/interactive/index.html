How to run it

1. Start the infrastructure

docker compose up -d
# Postgres :5432 · Kafka :9092 · Debezium :8083 · MLflow :5000
# MinIO :9000 (console :9001) · Adminer :8081 · Redpanda Console :8080

2. Train and register a model

python ml_service/train.py
# logs to MLflow, tags the new version 'staging',
# promotes it to 'production' only if RMSE beats the current production model

3. Start the services

uvicorn backend.main:app --reload          # REST API on :8000
python ml_service/main.py                  # streaming prediction consumer
streamlit run streamlit_app/app.py         # UI on :8501

4. Teaching scripts (data-quality concepts)

python ml_service/batch_validation.py    # batch SLA validation over landed data
python ml_service/dlq_tools.py --alert   # alerting app over the dead-letter topic
python ml_service/dlq_tools.py --recover # recovery app: fix + republish failed events
python ml_service/monitor.py             # drift report (PSI, predictions_log vs ford.csv)

Then add a car in the Streamlit UI and watch it travel: Postgres → Debezium → Kafka → ML service → predictions topic → backend → UI. Inspect topics in Redpanda Console (:8080) and tables in Adminer (:8081).
